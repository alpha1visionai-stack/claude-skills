Schritt 1

Installation & API-Keys

llm-council ist ein Plugin für Simon Willisons llm-Framework. Es wurde bereits installiert. Bevor du es nutzen kannst, brauchst du API-Keys für die Provider, die du befragen möchtest.

OpenAI
gpt-4o
platform.openai.com → API Keys
Anthropic
claude-3.5-sonnet
console.anthropic.com → API Keys
Google
gemini-1.5-flash
aistudio.google.com → Get API Key
1
Keys speichern

Führe diese Befehle nacheinander aus. Du wirst nach dem Key gefragt — dieser wird lokal verschlüsselt gespeichert.

PowerShell / Bash
llm keys set openai
llm keys set anthropic
llm keys set gemini
2
Installation prüfen

Zeigt alle gespeicherten Keys (ohne den Wert selbst):

Prüfen
llm keys
3
Erste Anfrage testen

Einfachster möglicher Test mit den Standard-Providern OpenAI + Anthropic:

Erster Test
llm council "Hallo, wer bist du?"

Ein Terminal-UI öffnet sich mit zwei Panels nebeneinander. Schließen mit q.

Hinweis

Einzelner Provider reicht. Du kannst llm-council auch mit nur einem API-Key starten — wähle den Provider explizit mit -p. Fehlende Keys erzeugen beim Start einen Fehler für den jeweiligen Provider.

Schritt 2

Grundlegende Benutzung

Der council-Befehl ist ein Subcommand des llm-CLIs. Die Frage wird als Argument übergeben — entweder als direktes Argument oder in Anführungszeichen.

Einfachste Form
llm council "Deine Frage hier"
Alle drei Provider befragen
llm council -p openai -p anthropic -p google "Erkläre Transformer-Architekturen in 3 Sätzen"
Nur Anthropic und Google
llm council -p anthropic -p google "Was ist der Unterschied zwischen RAG und Fine-Tuning?"
Mit eigenem System-Prompt
llm council -s "Antworte immer auf Deutsch, präzise und unter 100 Wörtern." "Was ist Quantencomputing?"
Tipp

Lange Fragen mit Pipe: Komplexe Prompts über echo oder Datei-Inhalte lassen sich direkt pipen — echo "..." | llm council ist aktuell noch nicht nativ unterstützt; nutze Anführungszeichen für mehrzeilige Fragen in der Shell.

Referenz

Alle Optionen

Flag Standard Beschreibung
-p / --providers openai, anthropic Provider, die befragt werden sollen. Kann mehrfach angegeben werden. Gültige Werte: openai, anthropic, google.
-s / --system "Keep your answers brief and to the point." System-Prompt für alle Provider. Überschreibt den eingebauten Standard-Prompt. Gilt für alle Provider gleichzeitig.
ARGS (Positional) — Die eigentliche Frage oder Aufgabe. Mehrere Wörter ohne Anführungszeichen werden zusammengefügt.

Die folgenden Modelle sind aktuell fest verdrahtet pro Provider:

Interne Modell-Zuordnung (aus llm_council.py)
# Stand v0.1.3 — nicht konfigurierbar ohne Code-Änderung
openai   → gpt-4o
anthropic → claude-3.5-sonnet
google   → gemini-1.5-flash-latest
Modell wechseln

Die Modell-Zuordnung ist in llm_council.py unter PROVIDER_MODELS definiert. Für persistente Anpassungen: Pfad mit python -c "import llm_council; print(llm_council.__file__)" finden und die Dict-Einträge bearbeiten.

TUI Navigation

Tastaturkürzel

Das TUI läuft im Vollbildmodus im Terminal. Alle Interaktionen passieren über die Tastatur.

Tab Fokus zum nächsten Panel wechseln — der aktive Puffer bekommt Cursor-Kontrolle
↑ / ↓ Im fokussierten Panel scrollen (bei langen Antworten)
q TUI beenden und zurück zur Shell
Ctrl + C TUI sofort abbrechen (gleichwertig zu q)
Hinweis

Die Panels sind read-only. Du kannst durch die Antworten scrollen, aber nichts bearbeiten. Zum Kopieren einer Antwort: TUI beenden und llm logs nutzen, um die letzte Konversation abzurufen.

Praxis

Typische Use Cases

Modell-Vergleich für Code-Reviews
Sieh, welches Modell welche Sicherheitslücken oder Verbesserungen in einem Code-Snippet identifiziert.
llm council -p openai -p anthropic -s "Du bist ein erfahrener Code-Reviewer. Sei präzise." "Reviewe diesen Python-Code: def get_user(id): return db.query(f'SELECT * FROM users WHERE id={id}')"
Technische Entscheidungen
Hol dir drei Meinungen zu Architektur-Entscheidungen, bevor du eine Richtung festlegst.
llm council -p openai -p anthropic -p google "PostgreSQL oder MongoDB für eine Event-Sourcing-Architektur mit 10M Events/Tag?"
Fakten-Konsens prüfen
Bei Informationen, die du verifizieren möchtest: wenn alle drei Models übereinstimmen, ist die Wahrscheinlichkeit höher.
llm council "Wann wurde das Transformer-Paper 'Attention Is All You Need' veröffentlicht?"
Prompt-Engineering testen
Verschiedene System-Prompts testen, um zu sehen, wie stark sie das Antwortverhalten beeinflussen.
llm council -s "Antworte ausschließlich mit Bullet Points, maximal 5 Punkte." "Was sind die wichtigsten Prinzipien von Clean Code?"
Fortgeschritten

Antworten weiterverarbeiten: llm speichert alle Konversationen in einer lokalen SQLite-Datenbank. Mit llm logs list und llm logs --json kannst du die Council-Antworten skriptbasiert weiterverarbeiten oder exportieren.

Logs abrufen nach einer Council-Session
# Letzte Konversation anzeigen
llm logs

# Als JSON exportieren
llm logs --json

# Letzten Eintrag
llm logs -n 1
Hilfe

Häufige Fehler

!
Unknown provider: google

Google heißt im Kontext von llm keys set gemini, aber in -p muss google angegeben werden. Die Benennung ist inkonsistent — das ist ein bekanntes Problem in v0.1.3.

Korrekte Verwendung
llm keys set gemini        # Key-Name
llm council -p google  # Provider-Name im council
!
TUI öffnet sich nicht / zeigt leere Panels

Passiert wenn ein API-Key fehlt oder ungültig ist. Jeder Provider wird sequenziell abgefragt — ein Fehler bei einem Provider verhindert die Anzeige aller Antworten.

Diagnose
llm keys           # gespeicherte Keys anzeigen
llm "Testfrage"      # direkter llm-Test ohne council
!
llm: command not found

Das llm-CLI ist installiert, aber nicht im PATH. Python-Scripts-Verzeichnis zum PATH hinzufügen:

Windows PowerShell
# Pfad herausfinden
python -c "import sys; print(sys.prefix + '\\Scripts')"

# Dann diesen Pfad zu PATH hinzufügen (System-Einstellungen)
# oder temporär:
$env:PATH += ";C:\Users\walte\AppData\Local\Programs\Python\Python313\Scripts"
