# 🔬 Fast-DetectGPT — Quickstart & Anleitung

Dieses Verzeichnis enthält die einsatzbereite Installation von **Fast-DetectGPT** (*Bao et al., ICLR 2024*).

## 🚀 Schnellstart

### 1. PowerShell-Starter (Windows)
```powershell
# Direkter Text:
.\detect.ps1 -Text "Dein Text hier..."

# Datei prüfen:
.\detect.ps1 -File "mein_text.txt"

# Interaktiver Modus:
.\detect.ps1
```

### 2. Python CLI (`uv`)
```powershell
uv run python detect_text.py --text "Dein Text hier..."
```
